# Todo API

A simple Todo REST API built using Node.js, Express, TypeScript, and MongoDB.

## Features

- Create Todo
- Get All Todos
- Update Todo
- Delete Todo
- REST API Architecture
- TypeScript Support
- Environment Variable Support using dotenv

---

## Tech Stack

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- dotenv
